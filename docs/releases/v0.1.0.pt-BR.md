# SMO Recomp Android v0.1.0 — Lançamento Inicial

[English](v0.1.0.md) | [Português do Brasil](v0.1.0.pt-BR.md)

Lançamento inicial do projeto de recompilação estática nativa de **Super Mario Odyssey** (v1.4.1) para Android AArch64. Construído em arquitetura modular desacoplada de biblioteca dupla (`libmain.so` + `smogame.so`) com otimizações em silício desenhadas para o Qualcomm Snapdragon 8s Gen 4 (Adreno 825) e Snapdragon 8 Elite (Adreno 830).

---

## Destaques

* **Arquitetura Dual de Recompilação Estática:**
  * `libmain.so`: Host de runtime móvel de alta performance com Vulkan 1.3, pacing de CPU sem spin-loop (`sleep_until`), entrada de toque de baixa latência e suporte a drivers customizados via AdrenoTools.
  * `smogame.so`: Código do jogo transpilado antecipadamente (AOT) e compilado via NDK Clang com flags `-O3 -flto -march=armv8.2-a+simd`.
* **Otimizações em Silício para Poco F7 (Snapdragon 8s Gen 4):**
  * **AAudio Exclusive Sink:** Saída de áudio direta abaixo de 32ms a 48.000 Hz, substituindo wrappers lentos de OpenSL/Oboe.
  * **Pacing Vulkan Não-Blocante:** Eliminação de spin-loops de CPU que causavam artefatos brancos e superaquecimento.
  * **Unswizzler SIMD ARM NEON de 128 Bits:** Transferências de 16 bytes em ciclo único (`vld1q_u8` / `vst1q_u8`) para texturas Block Linear.
  * **Mesa Turnip 8xx UMA Zero-Copy Hook:** Carregamento de driver customizado Turnip 8xx via `libadrenotools`.
  * **Afinidade Inteligente de CPU:** Thread do jogo no núcleo Prime Cortex-X4; workers amarrados no cluster Cortex-A720.
* **Suporte Nativo a Telas 20:9 (Hor+):**
  * Patch nativo de aspect ratio 20:9 (`patches/smo_aspect_ratio_20_9.txt`) atuando em `al::Projection::setAspect` para renderizar $+25.04\%$ de geometria horizontal sem esticar Mario.
* **Safe-Zone 2D de Interface:**
  * Elementos do HUD (moedas, luas, medidor de vida) mantidos em Safe-Zone centralizada 16:9 (`patches/smo_safe_zone_2d.txt`), protegendo contra cortes do orifício da câmera frontal (*punch-hole*).
  * Compensação automática de margem para controles touch em `nnpad_android.c`.
* **Empacotamento Android e Launcher:**
  * Projeto Gradle NDK (`settings.gradle.kts`, `build.gradle.kts`, `app/build.gradle.kts`).
  * NativeActivity em tela cheia de ponta a ponta com suporte ao recorte da câmera (`SHORT_EDGES`) e bloqueio do touch boost a 120Hz.
  * Seletor de RomFS via Storage Access Framework (SAF), alternador de driver Turnip e seletores de FPS (30/60).
  * Script automatizado de assinatura e alinhamento de 16 KB via `android/sign_apk.sh`.
