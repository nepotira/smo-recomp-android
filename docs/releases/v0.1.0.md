# SMO Recomp Android v0.1.0 — Initial Release

[English](v0.1.0.md) | [Português do Brasil](v0.1.0.pt-BR.md)

Initial release of the native static recompilation project of **Super Mario Odyssey** (v1.4.1) for Android AArch64. Built with a decoupled dual-library architecture (`libmain.so` + `smogame.so`) and silicon optimizations tailored for the Qualcomm Snapdragon 8s Gen 4 (Adreno 825) and Snapdragon 8 Elite (Adreno 830).

---

## Highlights

* **Dual-Library Static Recompilation Architecture:**
  * `libmain.so`: High-performance mobile runtime host with Vulkan 1.3 presentation, zero-spin CPU pacing (`sleep_until`), low-overhead touch input, and AdrenoTools driver hooking.
  * `smogame.so`: AOT lifted game code compiled ahead of time via Clang NDK with `-O3 -flto -march=armv8.2-a+simd`.
* **Silicon Optimizations for Poco F7 (Snapdragon 8s Gen 4):**
  * **AAudio Exclusive Sink:** Sub-32ms direct audio output at 48,000 Hz, replacing OpenSL/Oboe overhead.
  * **Vulkan Non-Blocking Frame Pacing:** Eliminated busy wait spin-loops, preventing white glitches and thermal throttling.
  * **128-Bit ARM NEON SIMD Unswizzler:** Single-cycle 16-byte Block Linear texture transfers (`vld1q_u8` / `vst1q_u8`).
  * **Mesa Turnip 8xx UMA Zero-Copy Hook:** Custom Adreno driver loading via `libadrenotools`.
  * **CPU Thread Affinity:** Game thread pinned to the Cortex-X4 Prime core; worker threads bound to Cortex-A720 cluster.
* **Native Hor+ 20:9 Aspect Ratio Support:**
  * Native 20:9 viewport patch (`patches/smo_aspect_ratio_20_9.txt`) overriding `al::Projection::setAspect` to render $+25.04\%$ extra horizontal geometry without stretching Mario.
* **2D UI Safe-Zone Isolation:**
  * HUD elements (coins, moons, life gauge) rendered into a centered 16:9 safe region (`patches/smo_safe_zone_2d.txt`), protecting against camera punch-hole clipping.
  * Ultra-wide touch control margin compensation in `nnpad_android.c`.
* **Android Packaging & Launcher:**
  * Gradle NDK project (`settings.gradle.kts`, `build.gradle.kts`, `app/build.gradle.kts`).
  * Full-screen edge-to-edge NativeActivity with display cutout support (`SHORT_EDGES`) and 120Hz touch boost suppression.
  * RomFS picker via Storage Access Framework (SAF), Turnip driver toggle, and 30/60 FPS selectors.
  * Automated 16KB-aligned packaging and signing pipeline via `android/sign_apk.sh`.
